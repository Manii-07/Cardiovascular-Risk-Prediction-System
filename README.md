## 📌 Project Overview
Cardiovascular diseases (CVDs) are the leading cause of death globally. This tool leverages historical clinical data to identify high-risk individuals, allowing for earlier intervention. The system provides an easy-to-use interface for healthcare providers or researchers to input patient metrics and receive an instant risk assessment.

### Key Features
*   **Real-time Prediction:** Instant risk categorization based on user input.
*   **Intuitive UI:** Clean web interface for seamless interaction.
*   **Scalable Backend:** Optimized Python-based inference engine.
*   **Cloud Hosted:** Deployed via Hugging Face for global accessibility.
